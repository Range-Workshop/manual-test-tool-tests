# Navigation and reports

## Dashboard and history

- [ ] Verify the dashboard repository and run totals match the data in the app.
- [ ] Open Recent runs and View all; verify each entry opens the correct run and shows its template title, date, and commit.
- [ ] Open a repository's run history and verify it contains only runs for that repository.

## Export

- [ ] Export Markdown; verify the report opens in the file manager and includes the run status, commit, result summary, sections, statuses, and notes.
- [ ] Export printable / PDF; verify the report opens and includes the same results and notes, then use the browser's Print dialog to save a PDF.
- [ ] Include characters such as `<`, `&`, and quotes in a note before exporting; verify they display as text rather than markup in the printable report.
