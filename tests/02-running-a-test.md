# Running a test

## Record results

- [ ] Start this template and verify it opens as an in-progress run with all items pending.
- [ ] Mark one item Pass, one Fail, one Skip, and one Blocked; verify each selected status is visible.
- [ ] Select an item's current status again; verify it returns to pending.
- [ ] Add a note with multiple lines, wait a second, and reload the run; verify the note and statuses persist.
- [ ] Verify progress counts every non-pending item as recorded and updates when an item returns to pending.

## Complete and resume

- [ ] Mark the run completed; verify its status changes in the run and history views.
- [ ] Reopen the run; verify it returns to in progress without losing item statuses or notes.
